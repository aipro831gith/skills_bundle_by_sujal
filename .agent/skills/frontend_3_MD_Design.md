# 3_MD_Design_Skill.md: Enterprise ERP & Financial Layout System

This modular front-end design skill is automatically selected by **Agent 05 (Front-End Builder)** when building Enterprise ERPs, Financial Systems, Accounting Dashboards, or Inventory Systems.

---

## 🏛️ ERP Layout Blueprint & Data Dense Components

### 1. Enterprise Component Structure:
* **Multi-Tab Workspace Layout:** Allows opening multiple active modules simultaneously in tabs (e.g., `Tab 1: Invoices`, `Tab 2: Inventory`, `Tab 3: Ledger`).
* **Dense Data Tables:**
  * Pagination controls (e.g. `Showing 1-50 of 10,000 records`).
  * Sortable and filterable column headers.
  * Sticky header row during vertical scrolling.
  * CSV/Excel export quick-action button bar.
* **Quick-Action Toolbar:** Top bar containing batch operations (e.g., `Approve Selected`, `Export PDF`, `Delete Rows`).

---

## 🎨 Enterprise High-Contrast Standards

* **Data Visual Density:** Optimized padding (`padding: 8px 12px` per table cell) to display high information density without clutter.
* **High-Contrast Dark Mode:** Inverted dark surfaces (`#121212` background, `#1E1E1E` card surfaces) designed to reduce eye strain during 8+ hour enterprise work sessions.
* **Status Badges:** Colored semantic badges (`Active` = Green, `Pending` = Amber, `Overdue` = Red, `Draft` = Gray).
